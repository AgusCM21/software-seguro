# ¿Qué es un Proxy?*

Un Proxy es un intermediario entre el cliente y el servidor. Cuando un usuario realiza una solicitud web, la petición primero pasa por el proxy, el cual puede observar, registrar, modificar o reenviar el tráfico antes de que llegue a su destino.

#Diferencia entre Proxy y VPN

Un proxy solo oculta la dirección IP para una aplicación o navegador específico sin cifrar los datos, mientras que una VPN (Red Privada Virtual) cifra todo el tráfico del dispositivo a nivel del sistema operativo.

*Proxy*

-Intercepta el tráfico de aplicaciones específicas.

-Permite visualizar y modificar peticiones HTTP y HTTPS.

-Es ampliamente utilizado en auditorías y pruebas de seguridad.

-No necesariamente cifra todo el tráfico del dispositivo.


*VPN*

-Crea un túnel cifrado entre el dispositivo y el servidor VPN.

-Protege todo el tráfico de red del sistema operativo.

-Se utiliza principalmente para mejorar la privacidad y seguridad de la conexión.

-No está diseñada para inspeccionar ni modificar peticiones individuales.
