
# Objetivo 1: Puertos y Servicios Esenciales
 
Los puertos de red permiten que distintos servicios se comuniquen a través de una red.
 
## Puerto 20
**FTP Data**
Se utiliza para la transferencia de datos en conexiones FTP activas.
 
## Puerto 21
**FTP (File Transfer Protocol)**
Permite la transferencia de archivos entre clientes y servidores.
 
## Puerto 22
**SSH (Secure Shell)**
Se utiliza para la administración remota segura de sistemas y la transferencia segura de archivos mediante SCP o SFTP.
 
## Puerto 23
**Telnet**
Permite el acceso remoto a un equipo, pero sin cifrado. Actualmente se considera inseguro.
 
## Puerto 25
**SMTP (Simple Mail Transfer Protocol)**
Se utiliza para el envío de correos electrónicos entre servidores de correo.
 
## Puerto 53
**DNS (Domain Name System)**
Se emplea para resolver nombres de dominio y traducirlos a direcciones IP.
 
## Puerto 80
**HTTP (HyperText Transfer Protocol)**
Se utiliza para la navegación web sin cifrado.
 
## Puerto 110
**POP3 (Post Office Protocol v3)**
Permite descargar correos electrónicos desde un servidor al cliente.
 
## Puerto 443
**HTTPS (HyperText Transfer Protocol Secure)**
Versión segura de HTTP que utiliza TLS/SSL para cifrar la comunicación.
 
## Puerto 3306
**MySQL**
Puerto utilizado por defecto por el sistema de gestión de bases de datos MySQL.
