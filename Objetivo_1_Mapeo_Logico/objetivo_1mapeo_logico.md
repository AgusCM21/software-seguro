Para este ejercicio elegí la aplicación web de Facebook.
-El usuario introduce su correo y contraseña.
-El Frontend de Facebook captura esos datos.
-Los datos viajan mediante HTTPS hacia el Backend.
-El Backend verifica las credenciales.
-El Backend consulta la base de datos.
-La base de datos devuelve el resultado.
-El backend responde al Frontend.
-El frontend muestra la página principal o un mensaje de error si es el caso.


El protocolo HTTPS ocurre entre el frontend y el backend, protegiendo la comunicación entre ellos en el tránsito de los datos.
